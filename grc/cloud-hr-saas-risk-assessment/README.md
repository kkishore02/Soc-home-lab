# Cyber Risk & GRC Assessment — Cloud HR SaaS

Personal GRC portfolio project assessing the security and privacy risks of a fictional UK organisation adopting a cloud HR SaaS platform.

## Scope

The assessment covers:
- Identity and access management
- Privileged access and MFA
- Supplier / third-party assurance
- Cloud configuration risk
- Vulnerability management
- Incident response
- Business continuity
- Privacy / UK GDPR screening

## Framework Alignment

The project references:
- NIST Cybersecurity Framework concepts
- ISO 27001-aligned control themes
- UK GDPR privacy principles

## Key Risks Identified

1. Privileged accounts without enforced MFA
2. Overly broad user access
3. Insufficient supplier-security assurance
4. Cloud misconfiguration exposure
5. Incomplete incident-response responsibilities
6. Business-continuity and supplier dependency risk

## Deliverables

- Risk register
- Control-gap analysis
- Third-party security assessment
- DPIA screening
- Executive summary
- Remediation ownership and residual-risk tracking

## Portfolio Integrity

This is a **fictional personal lab scenario** and is not presented as commercial GRC or legal work.
