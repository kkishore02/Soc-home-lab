# Executive Summary

A fictional UK organisation is considering adoption of a cloud HR SaaS platform. The assessment identified several material security and governance gaps before production use.

The highest-priority issue is privileged access without enforced multi-factor authentication. Additional high-priority gaps include excessive permissions, incomplete supplier assurance, cloud configuration governance and unclear incident-response responsibilities.

Recommended actions are to enforce MFA, implement role-based access control and periodic reviews, complete supplier due diligence, define a secure configuration baseline, clarify incident-response responsibilities and document business-continuity objectives.

The assessment uses NIST CSF and ISO 27001-aligned concepts as reference points and includes a lightweight UK GDPR / DPIA screening. This is an educational portfolio assessment, not legal advice.
